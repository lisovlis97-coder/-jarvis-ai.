# J.A.R.V.I.S. для Windows

Отдельное Windows-приложение на Electron. Оно подключается к существующему серверу J.A.R.V.I.S. и не меняет iPhone-версию.

## Запуск для разработки
Установите Node.js 22+ и выполните в папке `desktop`:

```powershell
npm install
npm start
```

## Создать установщик и portable .exe на Windows

```powershell
npm install
npm run dist
```

Результат — в `desktop/dist`. Для автоматической сборки используется GitHub Actions `Build JARVIS Windows`. Найдите успешный запуск во вкладке Actions репозитория и загрузите архив `jarvis-windows-exe` с файлами установщика и portable-приложения.

**Важно:** первые сборки без цифровой подписи. Windows SmartScreen может предупреждать об этом; скачивайте сборки только из собственного репозитория. Программа использует интернет для связи с Groq через Render, локальные команды управления Windows пока не реализованы. Локальная память приложения и iPhone не синхронизируется. 

## Автоматические обновления начиная с 1.2.0

Установленная Windows-версия проверяет GitHub Releases после запуска и примерно каждые шесть часов. При новой версии скачивает обновление и предлагает перезапустить программу. Проверка вручную: меню «Джарвис» → «Проверить обновления программы».

С версий 1.0/1.1 необходимо один раз установить JARVIS-Setup-1.2.0-x64.exe: они ещё не поддерживали встроенные обновления. Portable .exe не поддерживает автообновление. Установщик пока без цифровой подписи. Не отключайте антивирус и защиту Windows ради установки.

При дальнейших обновлениях увеличивайте поле version в desktop/package.json. GitHub Actions публикует выпуск desktop-vVERSION с latest.yml и инсталлятором; для этого у Actions должны быть права Contents: write. Успешный выпуск и работу обновления на Windows нужно проверить отдельно.
